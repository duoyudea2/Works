### [myproject-01: 基于SpringBoot的AI多语言文本生成与翻译平台](./myproject-01/)
- **技术栈**：Spring Boot + MyBatis + MySQL + Redis + HTML/JS (CompletableFuture结合自定义线程池，ConcurrentHashMap处理并发注册)
- **简介**：结合 DeepSeek 大模型的八字算命与多语言签诗解读应用。
- **功能**：用户注册/登录（Redis Token）、八字计算、多语言翻译。
