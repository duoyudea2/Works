# AI 智能运势解读系统

基于 Spring Boot + MyBatis + MySQL + Redis 的前后端分离 AI 应用。

## 功能
- 用户注册 / 登录（UUID Token + Redis）
- 八字计算（DeepSeek API）
- 签诗解读与多语言翻译
- 算命记录管理

## 技术栈
- 后端：Spring Boot、MyBatis、MySQL、Redis
- 前端：原生 HTML / CSS / JavaScript
- AI：DeepSeek API
- 工具：Maven、Git、Docker

## 本地运行
1. 启动 MySQL 和 Redis
2. 修改 `application.properties` 中的数据库和 API Key 配置
3. 运行 `Application.java`
4. 前端用 Live Server 打开

## 注意
本项目仅供学习，未部署公网服务。
